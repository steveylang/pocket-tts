# Tailscale Reader Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A private, single-user web app on this machine that reads pasted text or a web link aloud with pocket-tts, playable on an iPhone over Tailscale.

**Architecture:** A new `reader/` package (outside `pocket_tts/`) holds a FastAPI app that loads `TTSModel` once. `/prepare` turns text or a URL into sentence-aligned chunks of about 400 characters. `/chunk/{job}/{n}.wav` returns each chunk as a finished WAV (generated by a single-worker executor, so only one generation runs at a time, and the next chunk is queued ahead). A static page plays the chunks back-to-back in one `<audio>` element, with speed control and lock-screen controls. `tailscale serve` exposes it over HTTPS on port 8444.

**Tech Stack:** Python 3.10+, FastAPI, uvicorn, `requests` (already deps), `trafilatura` (new), `pytest`, plain JavaScript (no build step), systemd user service, Tailscale Serve.

**Spec:** `docs/superpowers/specs/2026-10-13-tailscale-reader-design.md`

## Global Constraints

- Do not edit anything under `pocket_tts/`. Only `reader/`, `pyproject.toml`, `uv.lock` and `docs/` change.
- The app binds to `127.0.0.1` only, port `8770`. Public exposure is only via `tailscale serve --https=8444`. The existing `:8443` proxy to `:8765` must not be touched.
- Chunk size is one constant, `MAX_CHARS = 400`. Jobs expire after 1 hour (`JOB_TTL_SECONDS = 3600`).
- Speed slider range is 0.75x to 2x, applied in the browser with pitch preserved.
- URL fetching refuses non-http(s) schemes and loopback, private, link-local, multicast, reserved, unspecified, and tailnet `100.64.0.0/10` addresses, re-checked on every redirect, with a timeout and a size cap.
- The generation model is not thread-safe: exactly one generation at a time (single-worker executor).
- Code style (ruff, from `pyproject.toml`): line length 100, type annotations on all functions (rule `ANN`, `-> None` may be omitted), absolute imports only (relative imports are banned), LF line endings, no magic trailing commas.
- Before every commit run `uvx ruff check --fix reader && uvx ruff format reader`.
- Work on the current branch `reader-tailscale-design`.

## Review Focus

Inputs the spec implies but does not spell out; each has a test in the task that owns the code.

1. **A huge paste with no punctuation** (a list, or 5000 characters of words) must still produce chunks no longer than `MAX_CHARS`. A single 1000-character "word" too. (Task 1)
2. **A link that redirects to an internal address**, or `http://localhost`, `http://127.0.0.1`, a `100.x` tailnet address, `file://`. Expect a clear refusal, never a fetch. (Task 3)
3. **A link that is a PDF, an image, or a huge page.** Expect a plain error, not a crash or memory blowup. (Task 3)
4. **Text that is only emoji, symbols, or links** (or a page that needs JavaScript). Expect "nothing readable", never an empty or garbage generation. (Tasks 2, 4, 5)
5. **Expired job, chunk number out of range, generation failure.** Expect 404, 404, and 500 followed by a working retry, and an iPhone-style `Range` request answered with 206. (Task 5)

`reader/chunking.py`:

```python
"""Split text into chunks of whole sentences, each short enough to generate in a few seconds.

The model splits each chunk again internally, so this only has to keep chunks small and avoid
cutting sentences in half.
"""

import re

# About 25 seconds of speech. Tune after listening on the phone.
MAX_CHARS = 400

# A sentence ends at . ! ? or … (plus closing quotes/brackets) followed by whitespace or the end
# of the text, so decimals such as 3.14 stay whole. The last sentence may lack punctuation.
_SENTENCE = re.compile(r".+?(?:[.!?…]+[\"'”’)\]]*(?=\s|$)|$)", re.DOTALL)
_CLAUSE_BREAK = re.compile(r"(?<=[,;:])\s+")
_PARAGRAPH_BREAK = re.compile(r"\n\s*\n")


def split_sentences(paragraph: str) -> list[str]:
    sentences = [match.group().strip() for match in _SENTENCE.finditer(paragraph)]
    return [sentence for sentence in sentences if sentence]


def _split_long(sentence: str, max_chars: int) -> list[str]:
    """Break an over-long sentence at commas/semicolons/colons, then at spaces, then mid-word."""
    if len(sentence) <= max_chars:
        return [sentence]
    pieces: list[str] = []
    for part in _CLAUSE_BREAK.split(sentence):
        line = ""
        for word in part.split():
            while len(word) > max_chars:
                if line:
                    pieces.append(line)
                    line = ""
                pieces.append(word[:max_chars])
                word = word[max_chars:]
            if line and len(line) + 1 + len(word) > max_chars:
                pieces.append(line)
                line = word
            else:
                line = f"{line} {word}".strip()
        if line:
            pieces.append(line)
    return pieces


def chunk_text(text: str, max_chars: int = MAX_CHARS) -> list[str]:
    units: list[str] = []
    for paragraph in _PARAGRAPH_BREAK.split(text):
        paragraph = " ".join(paragraph.split())
        for sentence in split_sentences(paragraph):
            units.extend(_split_long(sentence, max_chars))

    chunks: list[str] = []
    current = ""
    for unit in units:
        if current and len(current) + 1 + len(unit) > max_chars:
            chunks.append(current)
            current = unit
        else:
            current = f"{current} {unit}".strip()
    if current:
        chunks.append(current)
    return chunks
```

```python
"""Turn pasted text or a web page into clean text that is pleasant to hear."""

import re


class ExtractionError(Exception):
    """Something the user can fix or should know about; the message is shown on the page."""


class UnsafeURL(ExtractionError):
    """The link points somewhere the server must not fetch."""


_MARKDOWN_LINK = re.compile(r"\[([^\]]+)\]\([^)]*\)")
_URL = re.compile(r"https?://\S+|www\.\S+")
_LINE_MARKER = re.compile(r"^[ \t]{0,3}(?:#{1,6}[ \t]+|[-*+•][ \t]+|>[ \t]?)", re.MULTILINE)
_EMPHASIS = re.compile(r"[*`~]")
_PARAGRAPH_BREAK = re.compile(r"\n\s*\n")
_END_PUNCTUATION = ".!?…:;\"'”’)"


def clean_text(text: str) -> str:
    """Strip markup and links, join wrapped lines, and make every paragraph end in punctuation.

    Paragraphs are separated by a blank line in the result. Returns "" if nothing is readable.
    """
    text = _MARKDOWN_LINK.sub(r"\1", text)
    text = _URL.sub("", text)
    text = _LINE_MARKER.sub("", text)
    text = _EMPHASIS.sub("", text)

    paragraphs: list[str] = []
    for block in _PARAGRAPH_BREAK.split(text):
        block = " ".join(block.split())
        if not any(character.isalnum() for character in block):
            continue
        if block[-1] not in _END_PUNCTUATION:
            block += "."
        paragraphs.append(block)
    return "\n\n".join(paragraphs)
```

```python
Resolver = Callable[..., list[Any]]

MAX_PAGE_BYTES = 5_000_000
MAX_REDIRECTS = 5
_USER_AGENT = "Mozilla/5.0 (compatible; pocket-tts-reader)"
# Carrier-grade NAT space: this is where Tailscale addresses live. `is_private` does not cover it.
_BLOCKED_NETWORKS = [ipaddress.ip_network("100.64.0.0/10")]


def _is_blocked(address: ipaddress.IPv4Address | ipaddress.IPv6Address) -> bool:
    if isinstance(address, ipaddress.IPv6Address) and address.ipv4_mapped is not None:
        address = address.ipv4_mapped
    return (
        address.is_private
        or address.is_loopback
        or address.is_link_local
        or address.is_multicast
        or address.is_reserved
        or address.is_unspecified
        or any(address in network for network in _BLOCKED_NETWORKS)
    )


def check_url(url: str, resolve: Resolver = socket.getaddrinfo) -> None:
    """Raise unless the URL is http(s) and every address its host resolves to is public.

    Known limit: the host is resolved again when the request is made, so a hostile DNS server
    could answer differently the second time (DNS rebinding). Acceptable for one user on a tailnet.
    """
    parts = urlsplit(url)
    if parts.scheme not in ("http", "https") or not parts.hostname:
        raise UnsafeURL("Only http and https links can be read.")
    port = parts.port or (443 if parts.scheme == "https" else 80)
    try:
        infos = resolve(parts.hostname, port, type=socket.SOCK_STREAM)
    except socket.gaierror as error:
        raise ExtractionError(f"Could not find the website {parts.hostname}.") from error
    for info in infos:
        address = ipaddress.ip_address(info[4][0].split("%")[0])
        if _is_blocked(address):
            raise UnsafeURL("That link points to a private or internal address, so it was not read.")


def fetch_page(
    url: str,
    http_get: Callable[..., requests.Response] = requests.get,
    resolve: Resolver = socket.getaddrinfo,
) -> bytes:
    """Download a web page, checking every hop of a redirect chain and capping the size."""
    for _ in range(MAX_REDIRECTS + 1):
        check_url(url, resolve)
        try:
            response = http_get(
                url,
                headers={"User-Agent": _USER_AGENT},
                timeout=(5, 15),
                stream=True,
                allow_redirects=False,
            )
        except requests.RequestException as error:
            raise ExtractionError("Could not download that page.") from error
        with response:
            location = response.headers.get("Location")
            if 300 <= response.status_code < 400 and location:
                url = urljoin(url, location)
                continue
            if response.status_code >= 400:
                raise ExtractionError(f"The website answered with error {response.status_code}.")
            content_type = response.headers.get("Content-Type", "")
            if content_type and "html" not in content_type.lower():
                raise ExtractionError(f"That link is not a web page ({content_type}).")
            body = bytearray()
            for piece in response.iter_content(65536):
                body.extend(piece)
                if len(body) > MAX_PAGE_BYTES:
                    raise ExtractionError("That page is too large to read.")
            return bytes(body)
    raise ExtractionError("That link redirects too many times.")
```

```python
MIN_ARTICLE_CHARS = 200


@dataclass(frozen=True)
class Article:
    title: str
    text: str


def extract_article(page: bytes) -> Article:
    """Pull the main article out of a web page, without menus, comments, or tables."""
    extracted = trafilatura.extract(
        page,
        include_comments=False,
        include_tables=False,
        include_links=False,
        favor_precision=True,
    )
    # trafilatura puts one paragraph per line; clean_text wants blank lines between paragraphs.
    text = clean_text((extracted or "").replace("\n", "\n\n"))
    if len(text) < MIN_ARTICLE_CHARS:
        raise ExtractionError(
            "I couldn't find an article on that page. It may need JavaScript or a login."
        )
    metadata = trafilatura.extract_metadata(page)
    title = (metadata.title if metadata is not None else None) or text.split("\n\n")[0]
    return Article(title=title.strip(), text=text)
```

```python
"""Phone-friendly reader: paste text or a link, hear it read aloud one chunk at a time."""

import logging
import secrets
import shutil
import tempfile
import threading
import time
import wave
from collections.abc import AsyncIterator
from concurrent.futures import CancelledError, Future, ThreadPoolExecutor
from concurrent.futures import TimeoutError as FutureTimeout
from contextlib import asynccontextmanager
from dataclasses import dataclass, field
from pathlib import Path
from typing import Protocol

import numpy as np
import torch
from fastapi import FastAPI, HTTPException
from fastapi.responses import FileResponse
from fastapi.staticfiles import StaticFiles
from pydantic import BaseModel

from pocket_tts import TTSModel
from pocket_tts.utils.utils import _ORIGINS_OF_PREDEFINED_VOICES
from reader.chunking import chunk_text
from reader.extract import Article, ExtractionError, clean_text, extract_article, fetch_page

DEFAULT_VOICE = "alba"
JOB_TTL_SECONDS = 3600
# How long a chunk request waits for the (single) generator before saying "busy".
CHUNK_WAIT_SECONDS = 120
STATIC_DIR = Path(__file__).parent / "static"

logger = logging.getLogger(__name__)


class SpeechModel(Protocol):
    """The part of TTSModel the reader uses (tests substitute a fake)."""

    @property
    def sample_rate(self) -> int: ...

    def _cached_get_state_for_audio_prompt(self, voice: str) -> object: ...

    def generate_audio(self, model_state: object, text_to_generate: str) -> torch.Tensor: ...


def write_wav(path: Path, audio: torch.Tensor, sample_rate: int) -> None:
    """Write mono 16-bit PCM atomically, so a half-written file is never served."""
    samples = audio.detach().cpu().float().reshape(-1).clamp(-1.0, 1.0).numpy()
    pcm = (samples * 32767).astype(np.int16)
    partial = path.with_suffix(".part")
    with wave.open(str(partial), "wb") as out:
        out.setnchannels(1)
        out.setsampwidth(2)
        out.setframerate(sample_rate)
        out.writeframes(pcm.tobytes())
    partial.replace(path)


@dataclass
class Job:
    title: str
    voice: str
    chunks: list[str]
    created: float = field(default_factory=time.monotonic)
    futures: dict[int, "Future[Path]"] = field(default_factory=dict)


class ReaderService:
    """Holds the jobs and generates chunks, one at a time."""

    def __init__(self, model: SpeechModel, cache_dir: Path) -> None:
        self.model = model
        self.cache_dir = cache_dir
        self.jobs: dict[str, Job] = {}
        self._lock = threading.Lock()  # guards self.jobs and every job.futures
        # One worker: the model is not thread-safe, so generations queue up behind each other.
        self._executor = ThreadPoolExecutor(max_workers=1)

    def add_job(self, title: str, voice: str, chunks: list[str]) -> str:
        job_id = secrets.token_urlsafe(8)
        with self._lock:
            self._drop_expired()
            # Newest request wins: chunks of earlier readings that have not started are dropped,
            # so the new reading does not wait behind work nobody is listening to.
            for other in self.jobs.values():
                for n, future in list(other.futures.items()):
                    if future.cancel():
                        del other.futures[n]
            self.jobs[job_id] = Job(title, voice, chunks)
        return job_id

    def chunk_future(self, job_id: str, n: int) -> "Future[Path]":
        """Start (or find) generation of chunk n, and queue chunk n+1 behind it."""
        with self._lock:
            job = self.jobs.get(job_id)
            if job is None or not 0 <= n < len(job.chunks):
                raise KeyError((job_id, n))
            future = self._submit(job_id, job, n)
            if n + 1 < len(job.chunks):
                self._submit(job_id, job, n + 1)
            return future

    def shutdown(self) -> None:
        self._executor.shutdown(wait=False, cancel_futures=True)

    def _submit(self, job_id: str, job: Job, n: int) -> "Future[Path]":
        future = job.futures.get(n)
        if future is None:
            future = self._executor.submit(self._generate, job_id, job, n)
            job.futures[n] = future
        return future

    def _generate(self, job_id: str, job: Job, n: int) -> Path:
        path = self.cache_dir / job_id / f"{n}.wav"
        if path.exists():
            return path
        try:
            # generate_audio copies the voice state by default, so the cached state stays clean.
            state = self.model._cached_get_state_for_audio_prompt(job.voice)
            audio = self.model.generate_audio(state, job.chunks[n])
            path.parent.mkdir(parents=True, exist_ok=True)
            write_wav(path, audio, self.model.sample_rate)
        except Exception:
            with self._lock:
                job.futures.pop(n, None)  # forget the failure so a retry regenerates it
            raise
        return path

    def _drop_expired(self) -> None:
        """Remove old jobs and their files. Caller holds the lock."""
        now = time.monotonic()
        for job_id, job in list(self.jobs.items()):
            if now - job.created >= JOB_TTL_SECONDS:
                del self.jobs[job_id]
                shutil.rmtree(self.cache_dir / job_id, ignore_errors=True)


class PrepareRequest(BaseModel):
    input: str
    voice: str = DEFAULT_VOICE


def _title_from(text: str) -> str:
    first = text.split("\n\n")[0]
    return first if len(first) <= 60 else first[:57].rstrip() + "..."


def _looks_like_a_link(text: str) -> bool:
    return text.startswith(("http://", "https://")) and not any(c.isspace() for c in text)


def create_app(model: SpeechModel | None = None) -> FastAPI:
    """App factory. Run with: uvicorn reader.app:create_app --factory"""
    cache_dir = Path(tempfile.mkdtemp(prefix="pocket-tts-reader-"))

    @asynccontextmanager
    async def lifespan(app: FastAPI) -> AsyncIterator[None]:
        loaded = model if model is not None else TTSModel.load_model()
        app.state.service = ReaderService(loaded, cache_dir)
        yield
        app.state.service.shutdown()
        shutil.rmtree(cache_dir, ignore_errors=True)

    app = FastAPI(lifespan=lifespan)

    @app.get("/health")
    def health() -> dict[str, str]:
        return {"status": "healthy"}

    @app.get("/voices")
    def voices() -> dict[str, object]:
        return {"voices": list(_ORIGINS_OF_PREDEFINED_VOICES), "default": DEFAULT_VOICE}

    @app.post("/prepare")
    def prepare(request: PrepareRequest) -> dict[str, object]:
        if request.voice not in _ORIGINS_OF_PREDEFINED_VOICES:
            raise HTTPException(status_code=400, detail=f"Unknown voice: {request.voice}")
        text = request.input.strip()
        try:
            if _looks_like_a_link(text):
                article = extract_article(fetch_page(text))
            else:
                cleaned = clean_text(text)
                article = Article(title=_title_from(cleaned), text=cleaned)
            chunks = chunk_text(article.text)
            if not chunks:
                raise ExtractionError("There is nothing readable in that text.")
        except ExtractionError as error:
            raise HTTPException(status_code=400, detail=str(error)) from error
        job_id = app.state.service.add_job(article.title, request.voice, chunks)
        return {"job": job_id, "title": article.title, "chunks": len(chunks)}

    @app.get("/chunk/{job_id}/{n:int}.wav")
    def chunk(job_id: str, n: int) -> FileResponse:
        try:
            future = app.state.service.chunk_future(job_id, n)
        except KeyError:
            raise HTTPException(
                status_code=404, detail="That reading has expired or does not exist."
            ) from None
        try:
            path = future.result(timeout=CHUNK_WAIT_SECONDS)
        except (FutureTimeout, CancelledError):
            raise HTTPException(
                status_code=503, detail="The reader is busy. Try again in a moment."
            ) from None
        except Exception:
            logger.exception("Generating chunk %d of job %s failed", n, job_id)
            raise HTTPException(status_code=500, detail="Could not generate that part.") from None
        return FileResponse(
            path, media_type="audio/wav", headers={"Cache-Control": "private, max-age=3600"}
        )

    @app.get("/")
    def index() -> FileResponse:
        return FileResponse(STATIC_DIR / "index.html", headers={"Cache-Control": "no-cache"})

    if STATIC_DIR.is_dir():
        app.mount("/static", StaticFiles(directory=STATIC_DIR), name="static")
    return app
```

`reader/static/app.js`:

```javascript
"use strict";

const $ = (id) => document.getElementById(id);
const audio = $("audio");

let job = null; // { id, title, chunks }
let index = 0;

function safeGet(key) {
  try { return localStorage.getItem(key); } catch { return null; }
}

function safeSet(key, value) {
  try { localStorage.setItem(key, value); } catch { /* storage can be blocked; not essential */ }
}

function setStatus(text) {
  $("status").textContent = text;
}

// iOS only lets a page start audio from a tap, and the tap's permission is gone by the time the
// server has answered. Playing 0.1 s of silence inside the tap "unlocks" this audio element, so
// the real chunks can start later without another tap.
function silentWavUrl() {
  const rate = 8000;
  const samples = 800;
  const bytes = new Uint8Array(44 + samples * 2);
  const view = new DataView(bytes.buffer);
  const text = (offset, s) => [...s].forEach((c, i) => view.setUint8(offset + i, c.charCodeAt(0)));
  text(0, "RIFF"); view.setUint32(4, 36 + samples * 2, true); text(8, "WAVE"); text(12, "fmt ");
  view.setUint32(16, 16, true); view.setUint16(20, 1, true); view.setUint16(22, 1, true);
  view.setUint32(24, rate, true); view.setUint32(28, rate * 2, true);
  view.setUint16(32, 2, true); view.setUint16(34, 16, true);
  text(36, "data"); view.setUint32(40, samples * 2, true);
  return URL.createObjectURL(new Blob([bytes], { type: "audio/wav" }));
}

function applySpeed() {
  const speed = parseFloat($("speed").value);
  $("speed-label").textContent = `${speed.toFixed(2)}x`;
  audio.defaultPlaybackRate = speed;
  audio.playbackRate = speed;
  audio.preservesPitch = true;
  audio.webkitPreservesPitch = true;
  safeSet("speed", String(speed));
}

function chunkUrl(n) {
  return `/chunk/${job.id}/${n}.wav`;
}

function playChunk(n) {
  if (!job || n < 0 || n >= job.chunks) return;
  index = n;
  audio.src = chunkUrl(n);
  applySpeed();
  $("progress").textContent = `Part ${n + 1} of ${job.chunks}`;
  setStatus("");
  audio.play().catch(() => setStatus("Tap play to continue."));
  // The server already generates the next part ahead; fetching it here also warms the browser
  // cache so the switch between parts is instant.
  if (n + 1 < job.chunks) fetch(chunkUrl(n + 1)).catch(() => {});
}

function setupMediaSession() {
  if (!("mediaSession" in navigator)) return;
  navigator.mediaSession.metadata = new MediaMetadata({ title: job.title, artist: "Pocket Reader" });
  navigator.mediaSession.setActionHandler("play", () => audio.play());
  navigator.mediaSession.setActionHandler("pause", () => audio.pause());
  navigator.mediaSession.setActionHandler("previoustrack", () => playChunk(index - 1));
  navigator.mediaSession.setActionHandler("nexttrack", () => playChunk(index + 1));
}

async function start() {
  const input = $("input").value.trim();
  if (!input) {
    setStatus("Paste some text or a link first.");
    return;
  }
  audio.src = silentWavUrl();
  audio.play().catch(() => {});
  setStatus("Preparing…");
  $("play").disabled = true;
  try {
    const response = await fetch("/prepare", {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ input, voice: $("voice").value }),
    });
    const body = await response.json();
    if (!response.ok) {
      setStatus(body.detail || "Something went wrong.");
      return;
    }
    job = { id: body.job, title: body.title, chunks: body.chunks };
    $("title").textContent = job.title;
    $("player").hidden = false;
    setupMediaSession();
    setStatus("Generating the first part…");
    playChunk(0);
  } catch {
    setStatus("Could not reach the server.");
  } finally {
    $("play").disabled = false;
  }
}

async function loadVoices() {
  const response = await fetch("/voices");
  const { voices, default: fallback } = await response.json();
  for (const name of voices) {
    const option = document.createElement("option");
    option.value = option.textContent = name;
    $("voice").append(option);
  }
  const saved = safeGet("voice");
  $("voice").value = voices.includes(saved) ? saved : fallback;
}

$("play").addEventListener("click", start);
$("prev").addEventListener("click", () => playChunk(index - 1));
$("next").addEventListener("click", () => playChunk(index + 1));
$("voice").addEventListener("change", () => safeSet("voice", $("voice").value));
$("speed").addEventListener("input", applySpeed);
audio.addEventListener("ended", () => {
  if (job && index + 1 < job.chunks) playChunk(index + 1);
  else setStatus("Finished.");
});
audio.addEventListener("loadedmetadata", applySpeed);
audio.addEventListener("error", () => {
  if (job) setStatus("Could not load this part. Tap Next or Play to retry.");
});

const savedSpeed = parseFloat(safeGet("speed"));
if (savedSpeed >= 0.75 && savedSpeed <= 2) $("speed").value = String(savedSpeed);
applySpeed();
loadVoices().catch(() => setStatus("Could not load the voice list."));
```

````markdown
# Pocket Reader

A private page for listening to text or web articles on your phone, served over Tailscale only.
Design: `docs/superpowers/specs/2026-10-13-tailscale-reader-design.md`.

## Run it by hand

```bash
uv run --no-dev --group reader uvicorn reader.app:create_app --factory --host 127.0.0.1 --port 8770
```

The first start downloads the model weights, so it can take a while.

## Install as a service (this machine)

```bash
mkdir -p ~/.config/systemd/user
cp reader/pocket-tts-reader.service ~/.config/systemd/user/
systemctl --user daemon-reload
systemctl --user enable --now pocket-tts-reader
journalctl --user -u pocket-tts-reader -f      # wait for "Application startup complete"
curl -s http://127.0.0.1:8770/health
```

Linger is already enabled for this user, so the service starts at boot.

## Expose it on the tailnet

```bash
tailscale serve --bg --https=8444 http://127.0.0.1:8770   # may need sudo
tailscale serve status                                       # :8443 -> 8765 must still be listed
```

Then open `https://vnic1.tail6fc1ab.ts.net:8444` on the iPhone. Share > Add to Home Screen gives it
an app icon.

## Notes

- The server only listens on 127.0.0.1; Tailscale Serve is the only way in.
- One generation runs at a time. A new reading drops the not-yet-started parts of the old one.
- Pages that need JavaScript or a login cannot be read; the page says so.
````
